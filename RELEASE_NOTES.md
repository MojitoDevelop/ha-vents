# Vents 0.1.1

The integration now uses the official Vents brand emblem and full wordmark from the manufacturer's website. Brand assets include standard and double-resolution images.

Update Vents in HACS, restart Home Assistant, and refresh the frontend to load the new artwork.

The Modbus controls, entity IDs, and configuration retain the behavior of 0.1.0.

The attached ZIP supports manual installation; its SHA-256 checksum is provided separately. HACS uses the integration directory in this release tag.
